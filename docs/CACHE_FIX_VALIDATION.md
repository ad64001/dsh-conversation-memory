## 变更与回归

默认 `stable-prefix` 在新用户输入、路由切换或原生 surface 替换时刷新记忆包；同一轮普通工具步骤复用包，历史整理延后到原生替换边界。自动召回仅在能证明全部原文已可见时抑制副本；显式记忆工具保留。Go 适配器在独立的每次调用 snapshot 中使用真实会话 ID 设置 `x-opencode-session`，主请求与辅助请求一致；不改全局 fetch、原生 ASAR、共享 provider 配置或原生压缩阈值。详见 [实现说明](../LOCAL_CACHE_FIX.md)。

完整本地回归 **313/313**，无跳过，包括真实原生 Session、pi-ai 适配器及隔离安装/回滚检查。普通无桌面 CI 会跳过四项需要本机 DSH 的检查；离线回归无需模型额度。原生运行方式沿用 [验证指南](VALIDATION.md#公开安装器)。
