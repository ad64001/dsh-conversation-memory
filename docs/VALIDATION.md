公开版完整验证为 302/302：原有292项加10项安装器检查。无桌面环境运行 `npm test` 时两项原生检查跳过，其余300项不需要模型或网络。要运行原生 Session 和隔离安装检查，设置本机真实的 `DSH_EXE` 和 `DSH_RUNTIME_NATIVE_TEST=1`，再运行 `npm test`。这些检查以 Electron 的 Node 模式创建脱离用户会话的原生 Session 和临时 profile，不要求打开调试端口，不运行长程模型任务。

```powershell
$env:DSH_EXE = 'D:\Apps\DeepSeek Harness\DeepSeek Harness.exe'
$env:DSH_RUNTIME_NATIVE_TEST = '1'
npm test
```

## 不能据此保证的事情

- 任意模型、任务长度或工具格式都能成功；模型仍会有注意力、漏选和判断错误。
- 超大工具结果永远零丢失。DSH spill 可能先生成预览，临时文件遵循原生保留期限。
- 关键实体检测可以识别所有实体或所有语义约束。
- 全部上下文都被 6000 码点约束。这个上限只属于本插件 provider，其他 provider 和原生保留历史另计。
- 已验证所有平台、DSH 新版本或第三方 compaction backend。自动安装仅支持 Windows 0.2.1-rc.2。

失败时查看 memory_status 和回读原文，不把摘要或已批准但预算未准入的候选当作已完整查阅。
