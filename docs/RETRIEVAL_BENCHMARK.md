两个新库首请求均达到 500 ms 等待预算，明确返回未完成；其后的剩余归档用时分别为 1240.37 / 17688.94 ms，归档最终完整保存 1,000 / 10,000 条。不能把提前返回算作成功搜索，也不能把 500 ms 当严格端到端保证。

首次开发对照与回归并发执行，未用于本表；后续旧版和开发版的 10,000 条对照曾因状态文件替换失败中止。安全诊断确认开发版归档替换错误为 EPERM，已加入有界替换重试，持续失败仍报错。最终 10,000 条跑实际记录 2 次成功替换前的重试。旧版没有同样修改，因此不宣称本表是最终同条件 A/B 加速倍数。

这是固定合成材料、单机、有限样本的测量；P99 在小样本中接近最大值，不能作为服务等级承诺。没有清除 OS 文件缓存，没有运行 ES 或新的 Go API 压力长测。源码存储及实际证据校验继续使用原库。方法、配置、ES 预留接口和 KV 边界见 [说明](RETRIEVAL_AND_KV.md)。
